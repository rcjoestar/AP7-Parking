Pour créer notre site web de gestion de places de parking, nous allons créer des pages publique, avec un espace membre et un espace administrateur.
Nous utilisons Discord et Gmail pour faciliter l'envoi de documents. 
Pour développer le sie, nous utiliserons VSCode et NotePad pour certaines modifications simples. Les fichiers du projet
seront stocké dans un repo GitHub dans un dépôt commun, ce qui permettra à chaque membre de partager son tavail
et de voir les modifications.

Nous réaliserons aussi une base de données pour stocker toutes les informations concernant les membres, les places etc.. 
avec MySQL. 

Nous nous répartirons les tâches. Première étape : créer la structure du site et la BDD. Ensuite nous développerons les page
publiques, espace membre et admin. Puis enfin nous ferons des tests afin de vérifier le bon fonctionnement et corriger
les potentiels bugs.
